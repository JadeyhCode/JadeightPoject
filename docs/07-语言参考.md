## 0. 语言概览

`.j8` 是 Jadeight 生态的高级语言：**C 风格语法**、**面向协议**（protocol/impl + 存在类型动态分发）、
**ECS 内建**（component/system/spawn/get 等）、**泛型函数**（协议约束）。编译器 j8c 把它翻译为
Jadeight 汇编 `.jasm`（`-S` 保留）再汇编为 `.bc` 字节码，由 j8run / Jadeight2 VM 执行。

- 程序入口：`void main()`（缺失报错 `missing 'main' function`，sema.cpp）。
- 管线：词法 → 语法 → 语义 → 优化 → 代码生成（见 04 文档）。
- 编译：`./build/j8c input.j8 [-o out.bc] [-S] [-O0|-O1|-O2] [--stack N] [--ecs-capacity N] ...`
- 运行：`./build/j8run out.bc [--externs manifest] [--lib lib.so]`

**输出约定（重要）**：`.j8` 没有 `printf` 格式串；`print()` 的输出**每个字符/数字各占一行**
（底层是 `COUT_CHAR8`/`COUT_CHAR32` 指令，每次输出后换行；u32 等数字一次性输出整行，u64/i64/f64
由辅助函数逐位 `printc` 输出）。j8run 的第一行是 banner（`===== j8run: xxx =====`），
`tests/run_tests.sh` 用 `tail -n +2` 跳过它再与 `.expected` 比对。

## 1. 词法

词法分析器：`src/lexer.cpp`。诊断格式 `error:行:列: 消息`。

### 1.1 空白与注释

- 空白：空格、制表符、回车、换行。
- 行注释：`// ...`（到行尾）。
- 块注释：`/* ... */`（**不嵌套**；未闭合的块注释静默吞到文件尾）。

```j8
// t1_basic.j8 — 基础表达式、变量、print、类型（t1_basic 示例 第 1 行）
/* 块注释 */
```

### 1.2 标识符

`[A-Za-z_][A-Za-z0-9_]*`（字母或下划线开头）。大小写敏感。关键字不可用作标识符。

### 1.3 关键字（完整清单，来自 lexer.cpp 关键字表）

共 **25 个**：

| 关键字 | 用途 |
|---|---|
| `fn` | 系统方法声明（`fn update(ent e)`） |
| `return` | 返回语句 |
| `if` / `else` | 条件分支 |
| `while` / `do` / `for` | 循环 |
| `break` / `continue` | 循环控制 |
| `struct` | 结构体声明 |
| `protocol` | 协议声明 |
| `impl` | 协议实现 |
| `component` | ECS 组件声明 |
| `system` | ECS 系统声明 |
| `extern` | 外部函数声明 |
| `const` | 常量声明（**解析但不强制只读**，见 §12） |
| `new` | 堆分配（走 malloc extern，见 §7.4） |
| `delete` | **保留关键字，当前无语法支持**（parser 无对应规则） |
| `null` | 空指针字面量（类型 `void*`） |
| `true` / `false` | 布尔字面量 |
| `ent` | ECS 实体句柄类型 |
| `void` | 空类型 |
| `sizeof` | 大小运算符 |
| `world` | **保留关键字，当前无语法支持**（parser 无对应规则） |

> 内置类型名 `u8/u16/u32/u64/i8/i16/i32/i64/f32/f64/bool/char`、`ptr` 不是关键字，是
> 解析器识别的**特殊标识符**（`Parser::isTypeToken`）。`f32` 在语义阶段报错
> 「f32 不支持（v1 只支持 f64）」。

### 1.4 数值字面量

| 形式 | 示例 | 说明 |
|---|---|---|
| 十进制整数 | `123`、`10000000000` | `strtoull` 解析 |
| 十六进制 | `0xFF`、`0xABCD`（`0X` 亦可） | `strtoull(base 16)` |
| 二进制 | `0b1010`（`0B` 亦可） | `strtoull(base 2)` |
| 浮点 | `3.5`、`2.0`、`1e3`、`2.5e-2` | 小数点或 `e/E` 指数；`strtod` |

**整数字面量默认无符号**（sema.cpp `checkExpr` 的 IntLit 分支）：

- 值 ≤ `0xFFFFFFFF` → 类型 **u32**；
- 值 > `0xFFFFFFFF` → 类型 **u64**；
- **负数直接字面量**（解析器把「负号 + 整数字面量」标记为 `neg`）：
  `|值| ≤ 0x7FFFFFFF` → **i32**，否则 **i64**。

**没有后缀机制**：`0u`、`123L`、`1f` 等都不存在——`0u` 会被切成整数 `0` + 标识符 `u`，
编译报 `expected ';'`（实测验证）。类型只能靠值域推断或显式强转。

**无符号字面量的坑**：`0 - 7` 两个操作数都是 u32，结果按 u32 **回绕**为 `4294967289`；
要表达 -7 请写 `-7`（负数字面量）或显式声明 `i32 x = -7`。

```j8
// tests/t3_functions.j8 第 46-48 行（注释）：
// 有符号（整数字面量默认无符号：0 - 7 按 u32 回绕 = 4294967289）
print(negate(42));          // -42
print(negate(7));           // -7
```

### 1.5 字符串字面量

双引号包裹：`"hi"`。转义序列：

| 转义 | 含义 | | 转义 | 含义 |
|---|---|---|---|---|
| `\n` | 换行 0x0A | | `\\` | 反斜杠 |
| `\t` | 制表 0x09 | | `\'` | 单引号 |
| `\r` | 回车 0x0D | | `\"` | 双引号 |
| `\0` | NUL 0x00 | | `\xHH` | 十六进制字节（1–2 位） |

- 类型：`u8*`（即 `char*`，sema.cpp StrLit 分支）；存放于**数据段**，编译器自动追加 `0` 结尾
  （codegen.cpp `emitDataSection` 每串后 `dataByte(0)`）。
- `print("hi")` 经 `__print_str` 逐字符输出，**每个字符占一行**（见 §11）。
- 重复字面量去重（`emitted` 集合）。
- ⚠️ **控制字符进字符串字面量会导致汇编失败**：实测 `print("ab\ncd")` 报
  `Error: Unknown instruction`（jasm 文本数据段无法表示原始换行/制表字节）——**待确认**
  （`printc('\n')` 不受影响，因为它在运行期输出）。

### 1.6 字符字面量

单引号包裹：`'A'`、`'\n'`、`'\x41'`。转义同字符串（含 `\xHH`）。

- 词法值是一个 u64（`t.intVal`），**类型为独立的 `Char`**（`TypeKind::Char`，底层占 1 字节）。
- ⚠️ `Char` 与 `u8` 在类型系统里**不互通**（`TypeKind` 不同）：`u8 c = 'A';` 实测报错
  `cannot initialize 'c' (u8) with value of type 'char'`；字符字面量也不能参与算术
  （`'A' + 1` 报 `invalid operands to +/-: 'char' and 'u32'`）。字符字面量的可用位置：
  `print('A')`、`printc('x')`、`printc(65)`（数字 → 字符）、字符串内容、协议默认实现源码。
- `printc('A')` 输出字符；`print('A')` 同样逐字符一行。

```j8
// probe（实测）：print('A') → A；printc('x') → x；printc(65) → A；u8 c2 = 65; print(c2) → 65
```

### 1.7 布尔与 null 字面量

- `true` / `false`：类型 `bool`（= u8 宽度），`print` 输出 `true`/`false` 文本（逐字符一行）。
- `null`：类型 **`void*`**（sema.cpp NullLit 分支）。
  - ⚠️ 只能赋给 `void*` 目标；赋给 `T*`（T≠void）报错：`cannot initialize 'np' (u32*) with value of type 'void*'`（实测）。
  - ⚠️ **不能与整数 0 比较**：`p == 0`（指针 vs u32）报 `cannot compare`（实测）。
    空指针判等惯用法：`u64 n = (u64)p; print(n == 0);`（tests/t8_pointers.j8 第 75-77 行）或 `p == null`/`null == null`。
  - ⚠️ **`void*` 局部变量声明无法解析**（`void* vp = null;` 报 `unexpected token in expression`，
    因为 `parseStmt` 的声明前瞻只认「类型名后跟标识符」，而 `void*` 后跟的是 `*`）——待确认/已知限制。

### 1.8 运算符 token（词法全集）

```
( ) { } [ ] , ; : . -> ?
+ - * / %          算术
& | ^ ~ !          位/逻辑非
< > << >>          移位
&& || == != <= >=  逻辑/比较
= += -= *= /= %= &= |= ^= <<= >>=   赋值/复合赋值
++ --              自增/自减
```

### 1.9 `#pragma unroll N`（预处理指令）

- 语法：`#pragma unroll N`（`N` 为数字），放在一条 `for` 语句**之前**（顶层或函数体内均可）。
- 词法上整行到换行为止都算 pragma 文本；解析器在其中找 `unroll` 和数字（parser.cpp `parseProgram`/`parseBlock`）。
- 语义：给**下一条** `for` 打上「部分展开因子 N」标记（`pendingUnroll_` 在 `parseFor` 消费）。
  实际展开发生在 **-O2** 优化器（optimize.cpp）：余数 + 按 N 因子展开主体。
- `-O0` 下 pragma 被解析但**不产生展开效果**。

```j8
// tests/t7_unroll.j8 第 39-44 行：
#pragma unroll 3
    u32 pu = 0;
    for (u32 i = 0; i < 7; i = i + 1) {
        pu = pu + i;
    }
    print(pu);                    // 21
```

## 2. 类型系统

### 2.1 类型清单与宽度（common.h `typeWidth`、TypeKind）

| 类型名 | TypeKind | 宽度（字节） | 说明 |
|---|---|---|---|
| `void` | Void | 0 | 无值 |
| `u8` | U8 | 1 | 无符号 8 位 |
| `u16` | U16 | 2 | |
| `u32` | U32 | 4 | 最常用整数；`ent` 同宽 |
| `u64` | U64 | 8 | |
| `i8` / `i16` | I8/I16 | 1/2 | 有符号 |
| `i32` | I32 | 4 | |
| `i64` | I64 | 8 | |
| `f64` | F64 | 8 | **v1 唯一的浮点**；`f32` 报错 |
| `bool` | Bool | 1 | = u8 的语义宽度 |
| `char` | Char | 1 | 字符字面量类型；与 u8 不互通（见 §1.6） |
| `ent` | Ent | 4 | ECS 实体句柄（内部就是 u32） |
| `ptr` | Ptr(void) | 8 | 裸指针，即 `void*` |
| `T*` | Ptr(T) | 8 | 类型化指针 |
| 结构体 | Struct | 字段和（紧凑布局，无对齐填充，见 sema.cpp `structSize`） | `struct`/`component` 声明 |
| 协议存在类型 | Exist | 16 | 存在类型盒 `{data 8B, vt(witness) 8B}` |
| 泛型参数 | GenericParam | 8 | 泛型函数实例化时替换 |

类型字符串表示（`Type::str`）：`u8…f64`、`void`、`bool`、`char`、`ent`、`T*`、结构体/协议名。

### 2.2 基本规则

- **bool = u8、char = u8**（宽度），但作为独立 `TypeKind` 存在，`equals` 不同。
- **ent = u32**：双向隐式转换（`ent ↔ u32`，assignable 规则）。
- **指针宽度 8**；**存在类型盒宽度 16**（数据指针 + witness 指针）。
- 结构体大小 = 字段宽度**紧密相加**（无对齐/填充；`structSize` 逐字段 `off += sizeOf(fieldType)`）。
- 结构体参数/返回值按**地址**传递（槽占 8 字节指针）。

### 2.3 整数字面量类型推断（无符号陷阱）

见 §1.4。要点：

```j8
print(0 - 7);          // 4294967289（u32 回绕）——这是坑
i32 neg = -7;          // 负数字面量 → i32，正确得到 -7
print(negate(7));      // negate 的形参是 i64：0 - 7 按 i64 求值 → -7
```

（出处：tests/t3_functions.j8 第 46 行注释；04 文档 §3.1。）

### 2.4 二元运算的类型提升（sema.cpp `promoteBinary`）

- 操作数归一化：`bool`/`char` 视为 `u8`；`ent` 视为 `u32`。
- 任一为浮点 → **f64**。
- 都是整数：同宽时**有符号+无符号 → 无符号**；否则**宽者胜**（u64 > u32 > …）。
- 混合非数值 → 编译错误 `cannot mix operand types 'X' and 'Y'`。
- ⚠️ `char` 字面量是 Char 类型，**不参与**上述数值提升（算术直接报错，见 §1.6）。

### 2.5 隐式转换（sema.cpp `assignable`）

赋值/初始化/实参允许的隐式转换：

| 源 → 目标 | 允许？ |
|---|---|
| 相同类型 | ✓ |
| 数值 ↔ 数值（u8…f64 任意组合） | ✓（截断/回绕按目标宽度） |
| `bool ↔ 数值` | ✓ |
| `void* → T*` | ✓ |
| `T* → void*` | ✗（实测：`u32* np = null` 报错；反向被禁） |
| `T* → T*`（同 pointee） | ✓ |
| `ent → void*` | ✓ |
| `整数(含0/地址) → 任意指针` | ✓（`Point* nullp = 0;` 合法，t8 第 75 行） |
| `ent ↔ u32` | ✓ |
| `具体结构体 → 协议存在类型` | ✓ 但要求**该结构体已 impl 该协议**（触发 witness 登记，见 §8） |
| `结构体指针 → 协议存在类型` | ✓ 同上 |
| `协议存在类型 → 同名协议存在类型` | ✓（盒拷贝） |
| `泛型参数 ↔ 同名泛型参数` | ✓（同键） |

### 2.6 显式强转 `(T)expr`

允许的组合（sema.cpp `checkExpr` Cast 分支）：

- 数值 ↔ 数值（含 `(u32)3.9` 截断，t1 第 21 行）；
- 指针 ↔ 指针；`指针 ↔ u64`；`指针 ↔ ent`；
- `数值 → bool`；`u32 → ent`；
- `结构体/结构体指针 → 协议存在类型`（要求已 impl，触发 witness）。

```j8
print((u32)3.9);           // 3（t1_basic 示例 第 21 行）
u64 np = (u64)nullp;       // 指针 → u64（tests/t8_pointers.j8 第 76 行）
```

禁止的强转报 `cannot cast 'X' to 'Y'`。注意 `(T)expr` 的 T 若是自定义类型名，
需要解析器能确认它是「已声明的类型」（`typeNames_` 表）且后随 `)` 或 `*`（parser.cpp `parseUnary`）。

### 2.7 `sizeof`

- `sizeof(内建类型名)`：`sizeof(u32)` → 4；`sizeof(f64)` → 8。
- `sizeof(表达式)`：`sizeof(p)` → 结构体大小；`sizeof(p.x)` → 字段大小。
- 结果类型 **u32**，编译期常量（可折叠）。
- ⚠️ `sizeof(自定义结构体类型名)` **失败**（实测：`sizeof(Pt)` 报 `unknown identifier 'Pt'`，
  因为 `parseSizeof` 只把内建类型名当类型，其余当表达式解析）——待确认/已知限制。

```j8

```

## 3. 变量与声明

### 3.1 局部变量

```
类型 名字 [= 表达式] ;
类型 名字 = { 表达式, ... } ;     // 结构体字段初始化列表
const 类型 名字 = 表达式 ;         // const 前缀（不强制只读）
```

- 类型名：`u8…f64/bool/char/void/ent`、`ptr`、`T*`、结构体名、协议名、泛型参数名。
- 无初始化也可以（`Rect r;` 之后逐字段赋值，t8 第 22-30 行）。
- **同函数内重名报错** `redeclaration of variable 'x'`（sema.cpp）。
- 块作用域：`{}` 内声明的变量仅块内可见（帧布局按声明顺序，`layoutLocals`）。
- 数组声明：`T name[N]`，`N` 必须是常量整数；**数组退化为指针**（sema：`t = makePtr(t)`），
  帧里占 `N * sizeof(T)` 字节，变量值即首地址（见 §7.3）。

```j8
// tests/t2_control.j8 第 4-9 行：
i32 a = 10;
if (a > 5) {
    print("big");
} else {
    print("small");
}
// tests/t8_pointers.j8 第 15-17 行：
Point p = {3, 4};      // 结构体初始化列表
print(p.x);            // 3
```

### 3.2 指针变量 vs 数组 —— `x * y;` 歧义

解析器把「标识符 + `*` + 标识符」**一律当指针声明**（与 C 的 typedef 消歧同理）：

```
u32* p;                 // 指针变量
x * y;                  // 若 x 是变量：本意是乘法语句，但会被解析为「指针变量 y 的声明」！
```

因此**裸乘法表达式语句不可写**（必须赋值或用括号表达式）：`u32 z = x * y;` 是合法的
（声明初始化走表达式路径）。出处：parser.cpp 第 407-410 行注释；04 文档 §7；README 已知问题。

### 3.3 `const`

`const 类型 名字 = 值;` 可解析（`parseVarDecl(true)`），`isConst` 被记录，
但**没有任何地方强制只读**——`const u32 x = 5; x = 6;` 编译通过（实测源码检索：sema/codegen 未检查）。
按「可解析但无约束」记录。

## 4. 运算符

### 4.1 优先级与结合性（自低到高，源自 parser.cpp 的 parse 链）

| 优先级 | 运算符 | 结合性 |
|---|---|---|
| 1（最低） | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `|=` `^=` | 右 |
| 2 | `?:`（三目） | 右 |
| 3 | `\|\|` | 左 |
| 4 | `&&` | 左 |
| 5 | `\|` | 左 |
| 6 | `^` | 左 |
| 7 | `&` | 左 |
| 8 | `==` `!=` | 左 |
| 9 | `<` `<=` `>` `>=` | 左 |
| 10 | `<<` `>>` | 左 |
| 11 | `+` `-` | 左 |
| 12 | `*` `/` `%` | 左 |
| 13 | 一元：`!` `~` `-` `+` `&`（取址）`*`（解引用）`++`/`--`（前缀）`new` `sizeof` `(T)`（强转） | 右 |
| 14（最高） | 后缀：`()`（调用）`[i]` `.` `->` `++`/`--`（后缀）`<T>(...)`（泛型调用） | 左 |

### 4.2 算术

`+ - * / %`。整数除法截断（`10 / 3` → 3），`%` 要求整数操作数。
被零除/取模：编译期常量折叠时结果为 0（sema.cpp `evalConst` 中 `b.i == 0 → 0`）。

```j8
// t1_basic 示例 第 3-21 行：
print(1 + 2 * 3);          // 7
print(10 / 3);             // 3
print(10 % 3);             // 1
print(2 << 4);             // 32
print(255 & 15);           // 15
print(0xFF);               // 255
```

### 4.3 比较

`< <= > >= == !=`：结果 **bool**；仅允许 数值↔数值、指针↔指针
（`p == 0` 非法，见 §1.7）。浮点比较按双精度。

```j8
print(1 < 2);              // true（逐字符输出 t r u e，tests/t1_basic.expected）
print(5 == 5);             // true
print(5 != 5);             // false
```

### 4.4 逻辑

`&&` / `||`：结果 bool，**短路求值**（t2_control 第 81-87 行实测：右侧赋值不执行）。
`!`：一元取反，结果 bool。

```j8
// tests/t2_control.j8 第 81-87 行：
u32 calls = 0;
bool r1 = false && (calls = calls + 1) > 0;
print(calls);        // 0（右侧未执行）
bool r2 = true || (calls = calls + 1) > 0;
print(calls);        // 0（右侧未执行）
```

### 4.5 位运算

`<< >> & | ^ ~`（按位非）。要求整数操作数；移位量 `& 63` 截断。
无符号右移逻辑移位，有符号右移算术移位（sema `evalConst` 与 codegen 均区分）。无符号整数的
`*`/`/` 2 的幂在 -O2 强度削减为移位。

```j8
print(1 << 10);               // 1024（tests/t6_fold.j8 第 21 行）
print((255 & 240) | 15);      // 255（第 22 行）
print(0xABCD & 0xFFFF);       // 43981（第 29 行）
```

### 4.6 赋值与复合赋值

`=` 与 `+= -= *= /= %= <<= >>= &= |= ^=`；赋值是右结合表达式，值 = 目标新值。
复合赋值要求数值（或指针）目标。`x += 1` 等（t2 大量使用）。

```j8
// tests/t8_pointers.j8 第 43-46 行：
(*pp).x = 42;        // 解引用后赋值
pp->y = 43;          // 箭头成员赋值
```

### 4.7 自增/自减

`++x --x x++ x--`（前后缀都支持，`ExprKind::IncDec`）。要求 lvalue 且类型为
数值/指针/ent。注意：**测试与示例习惯用 `i = i + 1` 而非 `i++`**（优化器的循环展开
识别 `i = i + 1` 赋值步进；见 §5.4）。

```j8
u32 x = 5;
x++; print(x);   // 6
++x; print(x);   // 7
```

### 4.8 三目

`条件 ? 表达式1 : 表达式2`；条件须标量；两分支类型须兼容（数值走提升，或相同类型）。

```j8
// tests/t2_control.j8 第 90-93 行：
u32 m = (3 > 2) ? 111 : 222;    // 111
u32 m2 = (3 < 2) ? 111 : 222;   // 222
// tests/t6_fold.j8 第 27 行：
print(1 + 2 > 3 ? 100 : 200);   // 200（折叠后条件为假）
```

### 4.9 强转 / 取址 / 解引用 / 成员 / 下标

- `(T)expr`：见 §2.6。
- `&lvalue`：取地址，结果 `T*`；**非 lvalue 报错** `cannot take address of non-lvalue`。
- `*ptr`：解引用，结果 lvalue（可赋值）。
- `a.b` / `a->b`：成员访问（`->` 对指针/结构体均可——sema 先解一层指针；`->` 在 AST 用 `intVal=1` 标记）。
- `arr[i]`：下标，要求左侧是**指针**（数组已退化为指针），结果 lvalue，**无边界检查**。

```j8
// tests/t8_pointers.j8 第 40-46 行：
Point* pp = &p;
print(pp->x);                // 10
print(pp->y);                // 4
(*pp).x = 42;
print(p.x);                  // 42
pp->y = 43;
```

### 4.10 指针算术

- `ptr + 整数` / `整数 + ptr` → 指针（按元素步进）。
- `ptr - 整数` → 指针。
- `ptr - ptr` → **u64**（地址差，字节单位，不做除以元素大小的规约——待确认）。
- 下标 `p[i]` 等价于 `*(p + i)`。

```j8
// tests/t8_pointers.j8 第 57-61 行：
u32* ap = arr;
print(ap[1]);                // 22
ap[3] = 55;
print(arr[3]);               // 55
```

### 4.11 `new`

`new T`（单个对象）/ `new T[n]`（数组）：代码生成调用**自动注册的 `malloc` extern**
（codegen2.inc `emitNew`），分配 `n * sizeof(T)` 字节，返回 `T*`。
⚠️ 运行期需要 extern 注册（§7.4、§11.4）；本环境实测经 libffi 调 malloc 会段错误（待确认，见 §12）。

## 5. 语句

### 5.1 表达式语句

`表达式;`。结果值被丢弃。注意 `x * y;` 会被解析为声明（§3.2）。

### 5.2 块

`{ 语句* }`。块内可含 `#pragma unroll N`。

### 5.3 `if` / `else`

```
if (条件) 语句 [else 语句]
```

- 条件须标量（数值/bool/指针），否则报 `if condition must be scalar`。
- 单语句体可省略花括号；**else-if 链**通过嵌套 else 块实现（t2 第 16-23 行）。
- 无独立 `else if` 关键字。

```j8
// tests/t2_control.j8 第 16-23 行：
u32 score = 75;
if (score >= 90) {
    print("A");
} else if (score >= 60) {   // 实际是 else { if ... } 的嵌套
    print("B");
} else {
    print("C");
}
```

### 5.4 `while` / `do-while` / `for`

```
while (条件) 语句
do 语句 while (条件) ;          // 至少执行一次
for ([声明|表达式] ; [条件] ; [步进]) 语句
```

- `for` 初始化可以是**变量声明**（`for (u32 k = 1; ...)`，t2 第 47 行）或**表达式**（`for (i = 0; ...)`）；
  条件、步进都可省略。
- 步进惯用法 `i = i + 1`（**不是** `i++`——优化器的循环展开只识别前者为步进，见 t7 注释与 04 文档 §4）。
- 支持 `break;` / `continue;`（t2 第 52-69 行）。

```j8
// tests/t2_control.j8 第 46-50 行：
u32 acc = 0;
for (u32 k = 1; k <= 5; k = k + 1) {
    acc = acc + k;
}
print(acc);          // 15
// 同文件第 35-43 行：
u32 n = 0;
do {
    n = n + 1;
} while (n < 3);
print(n);            // 3
```

### 5.5 `return`

```
return [表达式] ;
```

- `void` 函数 `return;`（可省略表达式）；**非 void 必须返回值**，`void` 返回表达式报错。
- 返回值类型须可赋给函数返回类型。

```j8
// tests/t3_functions.j8 第 2-7 行：
u64 fib(u64 n) {
    if (n < 2) {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}
```

### 5.6 `print(...)` / `printc(...)`

见 §11。`print` 可带多个实参（逐个输出）。

### 5.7 `#pragma unroll N`

见 §1.9、§11 配套说明；仅 -O2 生效。

## 6. 函数

### 6.1 定义

```
返回类型 名字(参数列表) { 语句* }
```

- 返回类型：任意类型（含 `void`、结构体、协议存在类型、指针）。
- 参数列表两种风格（parser.cpp `parseParamList`）：
  - C 风格：`u32 a, f64 b, Point p`
  - Swift 风格：`a: u32, b: f64`（`名字: 类型`）
  - 特殊参数 `this`（协议方法专用，见 §8）。
- **参数按值传递**；结构体参数按**地址**传（槽 = 8 字节指针）。
- 函数声明不带 body（`ret name(...);`）**报错**：`function declaration without body
  (use 'extern' for external functions)`。

```j8
// tests/t3_functions.j8 第 9-19 行：
u32 add3(u32 a, u32 b, u32 c) {
    return a + b + c;
}
i64 negate(i64 v) {
    return 0 - v;
}
f64 celsius(f64 f) {
    return (f - 32.0) * 5.0 / 9.0;
}
```

### 6.2 递归

完全支持：`fib(25) = 75025` 深递归实测通过（t3_functions 第 66 行）。递归默认栈 **1MB**
（约 1.5 万层深递归），可用 `--stack N` 显式覆盖（codegen.cpp `computeStackSizes`：
递归时 `stackSize = opts_.stackSize > 0 ? stackSize : recursionStackSize`；
scopeSize 随栈放大 `max(64, stackSize/8)`）。

### 6.3 `extern` 声明（外部 C 函数）

```
extern 返回类型 名字(类型[, 类型...]) ;
```

- 参数名可选（可写 `extern i32 mymul_int(i32, i32);`，也可带名字，会被跳过）。
- 编译时用 `-emit-externs manifest.txt` 输出签名清单；j8run 用 `--externs` + `--lib` 经
  **libffi 原样调用**（VM 的 EXTERN_CALL 零封装）。
- ⚠️ `--lib` 的路径要能被 `dlopen` 找到：相对路径需带 `./` 前缀（实测：`--lib libmylib.so`
  找不到符号，`--lib ./libmylib.so` 正常）。
- 实测工作流（04 文档 §6 示例，本环境复测通过，输出 42）：

```j8
// extern 声明（docs/04 示例）：
extern i32 mymul_int(i32, i32);
void main() { print(mymul_int(6, 7)); }   // 42
```

```bash
gcc -shared -fPIC mylib.c -o libmylib.so
./build/j8c -O0 -emit-externs externs.txt -o out.bc prog.j8
./build/j8run out.bc --externs externs.txt --lib ./libmylib.so
```

### 6.4 入口 `main`

程序必须有 `void main()`（sema 报 `missing 'main' function`）。main 的序言负责
`STACK_INIT`、`GET_ADDRS`、分配并清零 **ECS world 堆**（codegen.cpp `emitPrologue`）。

### 6.5 泛型函数

```
返回类型 名字<参数[: 协议约束][, ...]>(参数列表) { ... }
```

- 实例化调用：`名字<具体类型>(实参...)`（§9）。
- 语义阶段**仅支持单个泛型参数**（`this version supports single generic parameter`）。

```j8
// t2_protocol 示例 第 17-19 行：
f64 total_area<T: Shape>(T a, T b) {
    return a.area() + b.area();
}
```

## 7. 结构体与指针

### 7.1 结构体定义与初始化

```
struct 名字 {
    类型 字段;
    ...
}
```

- 字段类型任意（含嵌套结构体、指针）；可省略末尾分号。
- 初始化：`T x = {a, b, ...}`（位置对应字段，数量 ≤ 字段数，多了报 `too many initializers`），
  或先声明再逐字段赋值。
- **值语义**：`Point p2 = p;` 是整结构体拷贝（t8 第 33-37 行实测：改 p2 不影响 p）。
- `sizeof(结构体变量)` = 字段宽度和。

```j8
// tests/t8_pointers.j8 第 2-11、15-30 行：
struct Point {
    i32 x;
    i32 y;
}
struct Rect {
    Point tl;      // 嵌套结构体
    i32 w;
    i32 h;
}
Point p = {3, 4};
Rect r;
r.tl.x = 1;        // 逐字段初始化嵌套结构体
r.tl.y = 2;
r.w = 5;
r.h = 6;
```

### 7.2 成员访问

- `.` 与 `->` 都可用（sema 对指针先解一层）；`pp->x`、`(*pp).x`、`p.x` 等价（t8 第 40-46 行）。
- 结构体不能直接 `print`（codegen 报 `cannot print struct 'X' directly`）。

### 7.3 数组（退化为指针）

```
类型 名字[N];        // N 必须是整数字面量常量
```

- 数组变量即指针：`u32* ap = arr;`（t8 第 58 行）；`arr[i]` 下标访问；无边界检查。
- 数组作为值取出时是**首地址**（帧内占 N×sizeof(T) 字节）。
- `new T[n]` 是堆数组（§4.11），局部数组在栈帧内。

```j8
// tests/t8_pointers.j8 第 49-55 行：
u32 arr[4];
arr[0] = 11;
arr[1] = 22;
arr[2] = 33;
arr[3] = 44;
print(arr[0]);               // 11
```

### 7.4 `malloc` / `free` / `memcpy`（自动注册的 extern）

编译器在语义阶段**自动注册**三个 extern（sema.cpp `addAutoExtern`，用户未声明时）：

| 名字 | 签名（manifest 形式） | 用途 |
|---|---|---|
| `malloc` | `ptr(u64)` | `new T` / `new T[n]` 的后端 |
| `free` | `void(ptr)` | 释放 |
| `memcpy` | `void(ptr,ptr,u64)` | 内存拷贝（codegen 有专用路径 `externMemcpy`） |

- 它们会出现在 `-emit-externs` 输出里；j8run 端**必须**用 `--externs` 注册
  （建议同时 `--lib libc.so.6` 或任何可 dlopen 的库——RTLD_DEFAULT 单独查 malloc 在本环境失败，实测）。
- 实测：`memcpy(b, a, 16)` 端到端可用（输出 33）；用户 extern（i32,i32）→ i32 可用（42）。
  `new`（malloc，返回 `ptr`）在本环境实测**段错误**（即使 extern 已注册）——**待确认**
  （可能与 emitNew 缺少 NEW_STACK 或 VM/libffi 交互有关，未深究）。

## 8. 协议与实现

### 8.1 协议声明

```
protocol 名字 {
    返回类型 方法名(this[, 参数...]) [; | { 默认实现 }]
}
```

- **每个协议方法第一个参数必须是 `this`**（否则报错 `must take 'this' as first parameter`）。
- 方法可只有声明（`;`），也可带**默认实现体**（`{ ... }`）——未覆盖该方法的 impl 自动使用。
- 协议名进入类型表，可作为**存在类型**使用（§8.4）。

```j8
// t2_protocol 示例 第 2-5 行：
protocol Shape {
    f64 area(this);
    f64 perimeter(this) { return 0.0; }   // 默认实现：未覆盖的类型自动使用
}
```

### 8.2 实现 `impl`

```
impl 协议名 for 类型名 {
    返回类型 方法名(this[, 参数...]) { ... }
}
```

- 一致性检查（sema `checkConformance`）：协议每个无默认实现的方法，impl 必须提供；
  否则报 `type 'X' does not implement protocol method 'P.m'`。
- impl 提供协议未声明的方法 → 仅警告。
- impl 类型必须是已声明 struct（`impl for unknown type` 报错）。

```j8
// t2_protocol 示例 第 10-15 行：
impl Shape for Circle {
    f64 area(this) { return 3.14159 * this->r * this->r; }
}
impl Shape for Rect {
    f64 area(this) { return this->w * this->h; }
}
```

### 8.3 静态派发（具体类型上的方法调用）

`c.area()`：编译期解析到 `impl_Shape_Circle_area` 实例（sema `checkMethodCall` Struct 分支）。

### 8.4 存在类型盒与动态派发（witness 表）

- 把实现了协议的具体值赋给**协议类型变量**（`Shape s1 = c;`）→ **boxing**：16 字节盒
  `{数据指针, witness 表指针}`；sema 自动 `ensureWitness` 构建 witness 表
  （数据段里每个方法一个 4 字节函数地址表，codegen.cpp `emitDataSection`）。
- `s1.area()`：**动态派发**——`resolved->isDynamicDispatch = true`，经 witness 表
  `witnessMethodIndex` 间接调用（codegen2.inc `emitDynamicCall`）。
- 盒可拷贝：`Shape box2 = box;`（t4 第 71-72 行）。
- 盒上调用协议未声明的方法报错；`s.x`（成员访问而非调用）报 `protocol member 'x' must be called`。
- 协议值可参与 `if` 等（t4 第 75-80 行）。

```j8
// t2_protocol 示例 第 32-45 行：
Shape s1 = c;            // 存在类型盒 + 动态派发（witness 表）
Shape s2 = r;
print(s1.area());       // 12.566360
print(s2.area());       // 12.000
Shape box = s1;
print(box.area());      // 12.566360
```

### 8.5 实测输出对照

f64 经 `__print_f64` 定点 3 位、逐字符一行（t2_protocol.expected 第 1-9 行 = `1 2 . 5 6 6 …` 即 12.566）。

## 9. 泛型

### 9.1 泛型函数

- 语法：`返回类型 名<T[: 协议][, U...]>(参数) { 体 }`（parser 允许多参数+约束）。
- 调用必须显式给类型实参：`名<类型>(实参...)`（不带 `<T>` 报
  `generic function 'x' must be called with type args`）。
- **仅支持单个泛型参数**（sema 报 `this version supports single generic parameter`）。
- 实例化：按 `函数名<类型串>` 键缓存（`getInstance`）；函数体在实例中**克隆**（避免类型注解冲突）。
- **递归实例化保护**：实例化中的函数再触发自身实例化 → 报 `recursive generic instantiation of 'key'`；
  函数体内调用本实例在注册后检查（先注册再 checkBody），所以**直接/间接递归调用是允许的**（sema.cpp 注释）。

```j8
// tests/t4_protocol.j8 第 39-41 行：
f64 total_area<T: Shape>(T a, T b) {
    return a.area() + b.area();
}
// 调用（第 66-67 行）：
print(total_area<Circle>(c, c));    // 25.132720
print(total_area<Rect>(r, r));      // 24.000
```

### 9.2 泛型约束下的方法调用

`T a` 上调用 `a.area()`：sema 在约束表里找 `T → Shape`，把调用解析为
`impl_Shape_<具体类型>_area`（`checkMethodCall` GenericParam 分支）。类型实参必须
**已 impl 该协议**，否则报 `type 'X' does not conform to protocol 'P'`。

### 9.3 泛型结构体

**当前无语法支持**（parser 的 `parseStruct` 不解析 `<T>`）；04 文档 §3.5 提到
「泛型函数/结构体按需实例化」，但源码只有函数泛型——**待确认**：泛型结构体应按未实现处理。

## 10. ECS

ECS 是编译器内建特性：world 是 **main 序言里分配并清零的堆数组**（`OP_NEW_ARRAY(worldBytes)`
+ 逐字节清零循环，codegen.cpp `emitPrologue`），所有组件/实体操作内联为 world 内存访问。

### 10.1 world 布局（sema.cpp `layoutComponents`、sema.h）

```
[0..4)    count（u32，实体数 = 下一个 spawn 下标）
[4..8)    cap（u32，容量，默认 --ecs-capacity 4096）
每个组件 C（按声明顺序）：
  [bitsetOff .. +ecsCapacity)    每实体 1 字节 presence（0/1）
  [dataOff   .. +ecsCapacity*sizeof(C))  紧凑数组：实体 e 的数据在 dataOff + e*sizeof(C)
```

### 10.2 组件与系统声明

```
component 名字 { 类型 字段; ... }
system 名字[: 组件名[, 组件名...]] {
    fn update(ent 参数名) { ... }
}
```

- `component` 与 `struct` 语法相同，但注册进组件表（`compIndex`）参与 world 布局。
- `system` 的组件列表可省略（`: 列表` 可选）；当前版本 `fn` 方法**只支持 `update`**
  （其他方法名报 `system only supports 'fn update(ent e)'`）。
- update 参数必须是 `ent`（1 个）。

```j8
// t3_ecs 示例 第 2-12 行：
component Pos { i32 x; i32 y; }
component Vel { i32 vx; i32 vy; }
component Health { i32 hp; }

system Physics: Pos, Vel {
    fn update(ent e) {
        get<Pos>(e)->x = get<Pos>(e)->x + get<Vel>(e)->vx;
        get<Pos>(e)->y = get<Pos>(e)->y + get<Vel>(e)->vy;
    }
}
```

### 10.3 实体与组件操作（全部内建函数，sema `checkEcsCall`）

| 调用 | 返回 | 语义（按源码 codegen2.inc `emitEcs`） |
|---|---|---|
| `spawn()` | `ent` | 返回旧 count 作为实体句柄；`count = count+1`；**满时**（count ≥ cap）打印 `world full` 并 `END` 退出 |
| `despawn(e)` | `void` | 若 `e+1 == count` 则 `count = e`（末尾实体才回收）；**清除所有组件的 bitset[e]** |
| `alive(e)` | `bool` | 实测即 `e < count`（槽位检查，非独立存活标志；见坑 §12） |
| `entity_count()` | `u32` | count |
| `add<C>(e, 字段值...)` | `void` | `bitset[e]=1`，按字段顺序写入数据区；实参个数须 = 1 + 字段数 |
| `remove<C>(e)` | `void` | `bitset[e]=0` |
| `has<C>(e)` | `bool` | `bitset[e]` |
| `get<C>(e)` | `C*` | 有组件 → `dataOff + e*sizeof(C)` 指针；**没有 → 空指针 0**（解引用会崩） |
| `run<S>()` | `void` | 遍历 e∈[0,count)，检查系统所需组件 bitset 全 1 后调用 `sys_S_update(e)` |

```j8
// tests/t5_ecs.j8 第 31-48 行：
ent a = spawn();
ent b = spawn();
print(entity_count());      // 2
add<Pos>(a, 1, 2);
add<Vel>(a, 3, 4);
add<Health>(a, 10);
add<Pos>(b, 100, 200);
print(has<Pos>(a));         // true
print(has<Health>(b));      // false
print(get<Pos>(a)->x);      // 1
get<Pos>(a)->x = 50;        // 直接改组件字段
print(get<Pos>(a)->x);      // 50
remove<Vel>(a);
print(has<Vel>(a));         // false
despawn(b);
print(alive(b));            // false（b 是末尾实体：count 1→... 见坑）
print(entity_count());      // 6
```

### 10.4 系统内实体字段糖

系统 update 里可以直接 `e.字段名`（sema `checkExpr` Member 的 Ent 分支 + codegen
`emitAddress` compIdx 分支）：按系统组件列表在 `world + dataOff(C) + e*size + fieldOff` 上
读写。限制：

- 只能在 system update 内使用（外部报 `entity field access only allowed inside a system update`）。
- 字段须属于该系统列出的组件（否则 `no component field 'x' in system 'S'`）。
- 多个组件含同名字段 → `ambiguous component field 'x'`。

```j8
// 用法（已实现，见 10.5）：
system Physics: Pos, Vel {
    fn update(ent e) {
        e.x = e.x + e.vx;    // e.x → Pos.x，e.vx → Vel.vx
    }
}
```

### 10.5 ✅ 实测：`run<System>()` 的 update 分发已生效

- **实现**（codegen2.inc `emitEcs` run 分支）：`count → t3`、`e → t4` 循环，
  对每个实体检查系统全部组件的 bitset（`world + bitsetOff + e`），全部为 1 则
  `SCOPE_PUSH` + 动态跳转调用 `sys_S_update(e)`（调用约定与普通函数一致：
  参数先求值到 R4，retOff = pc+31 + codeOff）。
- **实测**（`build/j8c` + `build/j8run`，-O0 与 -O2 均验证）：update 函数体**正常执行**——
  `tests/t5_ecs.j8` 中 `run<Physics>()` 后 `get<Pos>(a)->x` 50→53、y 2→6；
  `run<Heal>()` 后 hp 10→11；无所需组件的实体（b 无 Vel）不被处理（x 保持 100）。
  `.expected` 与这一行为一致（16/16 全绿）。
- **边界语义**（`tests/t9_ecs_run.j8` 覆盖，实测）：
  - **count 快照**：`e` 遍历上限是 run 开始时读的 count；update 里 `spawn()` 的新实体
    **本轮不被处理**（下次 run 才轮到）。
  - **嵌套 run**：update 里可再调 `run<Other>()`，每处理一个实体都会真正执行一次内层 run。
  - **run 中 `despawn(e)` 自己**：末尾实体 → count 回收（本轮剩余迭代自动跳过越界实体）；
    非末尾实体 → 按 despawn 语义清空组件 bitset（实体仍存活，`alive` 为 true）。
  - **remove 组件后**：该实体立即不再被任何 run 处理。
  - 空 world（count=0）跑 run 安全无副作用。
- 注：`sys_S_update` 在 sema 侧按 `DeclKind::System` 预实例化（`sema.cpp` buildInstance），
  codegen 直接取 `codeOff_` 静态跳转，无运行期查表开销。

### 10.6 容量与栈配置

- `--ecs-capacity N`：实体容量（默认 4096）；world 大小随之变化。
- `--stack N`：覆盖 VM 栈大小（递归默认 1MB；非递归自动 ≥ 16384）。

## 12. 已知坑与限制汇总

以下按「现象 / 影响 / 规避 / 来源」整理。来源列：**实测** = 本环境用 `build/j8c`+`build/j8run`
直接验证；**源码** = 从 src/ 逻辑推断；**文档** = 04/README 记载。

| # | 现象 | 影响 | 规避 / 备注 | 来源 |
|---|---|---|---|---|
| 1 | **整数字面量默认无符号**：`0 - 7` = 4294967289 | 无符号回绕 | 负数写 `-7`（自动 i32/i64）或显式类型 | 实测+文档 |
