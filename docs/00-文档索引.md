# 00. Jadeight 生态文档索引（从这里开始）

> 本文档是 Jadeight 全部项目的**统一文档入口**。**所有生态文档（虚拟机、汇编器、
> 编译器、启动器、游戏、教程）的实体都在本目录（`JadeightPoject/docs/`）**；
> 各仓库内只保留 README 级导航。

## 生态总览

| 项目 | 角色 | 语言/产物 | 仓库导航 |
|---|---|---|---|
| `Jadeight2` | 字节码虚拟机（解释器 + 快速模板 JIT） | C++，`.bc` 执行 | [README.md](../../Jadeight2/README.md) |
| `JadeightAbstractionCode` | 汇编层：jasm 文本 → 字节码 | C++ 头文件库，`jadeight_asm.hpp` | [README.md](../../JadeightAbstractionCode/README.md) |
| `JadeightCompiler` | C 风格编译器 `j8c` + 宿主运行器 `j8run` | C++，`.j8` → `.bc` | [README.md](../../JadeightCompiler/README.md) |
| `JadeightPoject`（本目录） | 启动器 + **文档中心** | C++/shell | [docs/05](05-JadeightPoject启动器.md) |
| `JadeightGame` | 示例游戏：SDL2 方块跑酷（.j8 编写） | C++ shim + `.j8` 字节码 | [README.md](../../JadeightGame/README.md) |
