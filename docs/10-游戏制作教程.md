# 从零做游戏：方块跑酷改造教程

> 本教程**不需要任何编程基础**。你只需要会三件事：**打开文件、改数字、保存**。
> 我们会拿现成的方块跑酷游戏（JadeightGame）当积木，一步步把它变成**你的**游戏。
>
> 📚 生态文档总入口（语言手册/VM/指令集/工具链）：[00-文档索引.md](00-文档索引.md)

## 开始之前：认识你的游戏

你的游戏长这样：

- 窗口里有一个**绿色方块**（你）
- 会有一个**红色方块**（障碍）从右边滚过来
- 按**空格**跳起来躲开它
- 撞上了就 Game Over

游戏的全部"配方"都在一个文件里：

```
CLionProjects/JadeightGame/game.j8
```

**记住三个动作：**

1. **打开** `game.j8`（用记事本、VS Code 或任何文本编辑器都行）
2. **改数字**（教程会告诉你改哪个、改成什么）
3. **保存**，然后运行看效果

### 你的游戏跑在 Jadeight2 生态上

这个游戏不是普通程序——它是 **Jadeight2 生态**里造出来的字节码游戏。
整个生态有四件套，各干一件事：

```
Jadeight2（虚拟机）     —— 真正"跑"游戏的东西，一个字节码解释器
jadeight_asm（汇编器）  —— 把汇编文本变成字节码
j8c（编译器）           —— 把你写的 J8 语言翻译成字节码（翻译机）
JadeightPoject（启动器） —— 一键找到虚拟机、把游戏跑起来
```

你改的 `game.j8` 是 **J8 语言**写的（一种很像 C 的编程语言）。
从你的文件到游戏窗口，流程是这样的：

```
game.j8（配方文本，你改的就是它）
   │  j8c 翻译
   ▼
game.bc（字节码：给虚拟机读的"菜谱"）
   │  j8run 启动 Jadeight2 虚拟机执行
   ▼
窗口里的游戏（SDL2 负责画，spdlog 负责记日志）
```

用大白话说：**你改的是菜谱（game.j8），j8c 把它翻译成机器能读的菜谱（game.bc），
Jadeight2 虚拟机照着菜谱把游戏做出来。** 游戏里连 SDL2（图形库）和 spdlog（日志库）
都是游戏运行时自己"打电话"（dload 动态链接）叫来的——这就是这个生态最酷的地方。

所以教程里你学到的每一样东西，都是在 **Jadeight2 生态**里造游戏：
同一个 VM、同一套工具链，以后想造别的游戏、甚至别的程序，方法一模一样。

### 怎么运行游戏

```bash
cd CLionProjects/JadeightGame
./run.sh          # 第一次先跑 ./build.sh
```

游戏窗口出现 = 成功。关闭窗口或按 ESC 退出。

## 第 1 课：给玩家换颜色（最最简单的改动）

游戏里的颜色是由**三个数字**组成的：**红、绿、蓝**，每个从 0 到 255。
（0 = 没有这种颜色，255 = 最浓。三个数字合起来就是一块颜色。）

打开 `game.j8`，找到这一行（第 92 行）：

```
dl_call(i_col, "i32(ptr,i32,i32,i32,i32)", ren, 80, 220, 100, 255); // 玩家：绿色
```

中间那三个数字 `80, 220, 100` 就是玩家的颜色（红 80、绿 220、蓝 100 = 绿色）。

**试试**：把 `80, 220, 100` 改成 `255, 180, 0`（橙色），保存，运行。

```
dl_call(i_col, "i32(ptr,i32,i32,i32,i32)", ren, 255, 180, 0, 255);  // 玩家：橙色
```

你的方块变橙色了！**第一个改动完成 🎉**

**常见颜色速查**（红, 绿, 蓝）：

| 颜色 | 数字 |
|---|---|
| 红色 | `255, 0, 0` |
| 橙色 | `255, 180, 0` |
| 黄色 | `255, 255, 0` |
| 绿色 | `80, 220, 100` |
| 蓝色 | `0, 120, 255` |
| 紫色 | `180, 0, 255` |
| 粉色 | `255, 100, 180` |
| 白色 | `255, 255, 255` |

> 想调出任何颜色？搜索"RGB 颜色对照表"，把看到的三个数字抄进来就行。
> 最后那个 `255` 是透明度，**永远不要改它**。

## 第 2 课：让游戏变快 / 变慢

找到这一行（第 43 行）：

```
i32 speed = 5;      // 障碍滚过来的速度
```

- 改成 `8`：障碍跑得更快，游戏更难
- 改成 `3`：更慢，更好上手

```
i32 speed = 8;      // 现在快多了！
```

保存运行，感受一下差别。

## 第 3 课：跳得更高 / 落地更快

两个数字管着跳跃：

**跳跃力量**（第 70 行）：

```
if (sp == 1 && py >= ground) { vy = -12.0; }     // -12 是起跳速度
```

数字越大（越负）跳得越高：`-12.0` → `-18.0` = 跳得更高。

**重力**（第 47 行）：

```
f64 grav = 0.6;     // 重力：把方块往下拉的速度
```

- `grav` 越大：掉得越快，跳跃弧线更"重"
- `grav` 越小：飘着跳

```
f64 grav = 0.4;     // 更飘的跳跃
```

## 第 4 课：让障碍变大变小

找到第 51-52 行：

```
i32 ow = 40;        // 障碍宽
i32 oh = 40;        // 障碍高
```

- `ow = 80`：障碍变宽一倍，更难躲
- `oh = 20`：障碍变矮，更容易跳过去

数字单位是"像素"（屏幕上的小点）。窗口是 800×600 像素，所以 40 = 屏幕宽度的 1/20。

## 第 5 课：造第二个障碍（复制粘贴大法）

这是最激动人心的一步：**自己造一个东西**。

游戏里障碍的全部"零件"是这几行：

```
i32 ox = 850;       // 障碍从右边开始（850 = 屏幕外面）
i32 oy = 410;       // 障碍离地面多高
i32 ow = 40;        // 宽
i32 oh = 40;        // 高
```

加上让障碍动起来、画出来的三行（第 76、78、95 行附近）。

**做法：把这些"零件"复制一份，改个名字（把 `ox` 改成 `ox2`、`oy` 改成 `oy2`……），就得到第二个障碍。**

跟着做：

**①** 在第 52 行后面加四行（复制，名字加个 2）：

```
i32 ox2 = 1200;     // 第二个障碍，从更远的地方来
i32 oy2 = 300;      // 飞得更高（300 = 离地更远）
i32 ow2 = 30;       // 更小
i32 oh2 = 30;
```

**②** 在第 76 行（`ox = ox - speed;`）后面加一行，让第二个障碍也动：

```
ox2 = ox2 - speed - 3;    // 比第一个还快一点
```

**③** 在第 78 行（`ox = 850;`）后面加三行，让第二个障碍到左边后重新从右边出现：

```
if (ox2 < -50) { ox2 = 1200; }
```

**④** 在第 94 行（画第一个障碍的 `i_fill`）后面加一行画第二个：

```
dl_call(i_fill, "i32(ptr,i32,i32,i32,i32)", ren, ox2, oy2, ow2, oh2);
```

保存，运行。**你造出了第二个障碍——游戏现在是你的了！**

> 小贴士：想加第三个？把 2 换成 3，再来一遍。想加一百个？方法一样，就是费手。

## 第 6 课：改窗口标题

第 33 行：

```
ptr win = dl_call(i_win, "ptr(ptr,i32,i32)", "J8 Block Runner", 800, 600);
```

- `"J8 Block Runner"` 是窗口标题——改成你的名字，比如 `"我的第一个游戏"`
- `800, 600` 是窗口宽高——改成 `1280, 720` 就是大窗口

```
ptr win = dl_call(i_win, "ptr(ptr,i32,i32)", "我的第一个游戏", 1280, 720);
```

## 第 7 课：游戏是怎么转起来的（大白话版）

你不需要懂这个也能玩，但知道了你会更有底气。

游戏其实是一个**无限循环**，每秒钟跑大约 60 圈，每圈做四件事：

```
┌─────────────────────────────────┐
│ ① 看有没有人按了键 / 关了窗口      │  ← 事件
│ ② 算一算方块现在该在哪（跳/落）     │  ← 物理
│ ③ 把障碍往左挪一点                │  ← 移动
│ ④ 把画面整个重画一遍              │  ← 渲染
└─────────────────────────────────┘
        ↑____________ 画完回到 ①
```

你改的那些数字，就是告诉电脑"每圈算的时候用这个数"。
比如 `speed = 8` = "每圈把障碍往左挪 8 像素"。

`while (quit == 0) { ... }` 就是那个循环；`quit` 变成 1 时循环结束、游戏关闭。

## 附录 A：改完没效果？检查这四件事

1. **保存了吗？**（很多编辑器要 Ctrl+S）
2. **重新运行了吗？**（改了代码要重新运行 `./run.sh`；如果改了 `build.sh` 才需要重编）
3. **改对行了吗？**（行号可能因为前面的改动往后挪了，按内容找，别只按行号）
4. **数字格式对吗？**（整数不带小数点：`8` 不是 `8.0`；位置/速度用整数，跳跃/重力带小数点：`-12.0`、`0.6`）

## 附录 B：把游戏改坏了怎么办

- 改错导致运行不了？**把刚才改的地方改回去**，或者从 git 恢复：
  ```bash
  cd CLionProjects/JadeightGame
  git checkout game.j8      # 恢复成最初版本
  ```
- 游戏窗口黑屏？回到第 1 课，确认玩家颜色不是 `24, 24, 40`（那是背景色，画了也看不见）
