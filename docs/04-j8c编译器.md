# 04. j8c 编译器（JadeightCompiler）

`j8c` 是 Jadeight 生态的**编译器**：把 C 风格、面向协议 + ECS 的 `.j8` 源码编译为
Jadeight 字节码 `.bc`。管线为 词法 → 语法 → 语义 → 优化 → 代码生成（jasm 汇编文本）→
复用 `jadeight_asm` 汇编器 → `.bc`。配套 `j8run` 宿主运行器直接在 Jadeight2 VM 上执行。

## 1. 定位与管线

```
.j8 源码
  │  lexer（src/lexer.cpp）—— 词法分析
  │  parser（src/parser.cpp）—— 语法分析（AST：src/ast.h）
  │  sema（src/sema.cpp）—— 语义分析：类型检查、协议实现、泛型实例化、ECS、
  │                         内置 print 助手（__print_u64 等）由源码文本解析构建
  │  optimize（src/optimize.cpp）—— 常量折叠/传播、循环展开、DCE、强度削减
  │  codegen（src/codegen.cpp + src/codegen2.inc）—— 生成 jasm 汇编文本
  ▼
.jasm 汇编文本（-S 保留）
  │  jadeight_asm（JadeightAbstractionCode，driver.cpp 内嵌 include）
  ▼
.bc 字节码（LE 头 + 指令流，FunctionSave/loadFromFile 兼容）
  │  j8run / Jadeight2 VM
  ▼
输出
```

## 2. 命令行用法

```
./build/j8c [选项] 源文件.j8
```

| 选项 | 说明 |
|---|---|
| `-O0` / `-O2` | 优化级别；`-O2` 为实验性/不稳定（见 §7），默认建议 `-O0` |
| `-o 文件` | 输出 `.bc` 路径（默认从输入名推导） |
| `-S` | 保留生成的 `.jasm` 汇编文本（输出名去掉扩展名 + `.jasm`） |
| `--dump-ast` | 打印 AST |
| `-emit-externs 文件` | 输出外部函数清单（供 j8run 注册） |
| `--unroll-limit N` | 循环展开上限 |
| `--ecs-capacity N` | ECS world 容量 |
| `--stack N` | VM 栈大小 |
| `-v` | 详细输出 |
| `-h` | 帮助 |

运行：`./build/j8run out.bc`（j8run 是宿主运行器，见 §6）。

## 3. 语言参考

### 3.1 类型

整数 `u8/u16/u32/u64`、`i32/i64`、浮点 `f64`、`bool`、指针（`*`）、结构体、协议、泛型、
ECS 组件。**整数字面量默认无符号**：`0 - 7` 按 u32 回绕为 `4294967289`；负数请写 `-7`
（解析器把「负号+整数字面量」标记为有符号）或显式 `i32` 类型。

### 3.2 语句

- 变量声明：`u32 x = 5;`、`i32 neg = -7;`、指针声明 `i32* p;`
- `if/else`、`while`、`for`、`return`
- `print(表达式)`：按类型分发到 `__print_u64/u32/i64/f64/str/bool` 等内置助手
- `#pragma unroll`（块内生效，配合 -O2 循环展开）
- 复合赋值、自增/自减

### 3.3 表达式

字面量、算术（`+ - * / %`）、位运算（`<< >> & | ^ ~`）、比较（`< <= > >= == !=`）、
逻辑（`&& || !`）、三元 `?:`、`(T)expr` 强转、`sizeof`、取址 `&`/解引用 `*`、
结构体成员 `.`、数组/索引、函数调用、泛型调用 `get<T>(...)` 等。

### 3.4 函数

```c
u64 fib(u64 n) { if (n < 2) return n; return fib(n - 1) + fib(n - 2); }
u32 add3(u32 a, u32 b, u32 c) { return a + b + c; }
void report(u32 v) { print(v); }     // void 无返回值
void main() { ... }                   // 程序入口
```

支持递归（`fib(25)` = 75025 深递归验证过）、嵌套调用、返回值参与运算、有符号/浮点参数。
参数按值传递。

### 3.5 协议与泛型

- **面向协议**：`protocol` 声明接口，结构体用 `impl` 实现协议；通过协议类型做多态
  分发（`resolved->isDynamicDispatch` 走动态调用，见 `codegen2.inc` 的 `emitDynamicCall`）。
- **泛型**：泛型函数/结构体按需实例化；实例在 `checkBody` 前注册，避免递归实例化死循环。

### 3.6 ECS

内置组件与实体操作（经 `emitEcs` 生成 world 访问代码，world 是编译器在 main 序言里
清零的堆数组）：`spawn/despawn/alive/entity_count`、`add/remove/has/get` 组件、
`run` 系统。示例见 `tests/t5_ecs.j8`。

## 4. 优化器（src/optimize.cpp）

- **常量折叠**：`evalConst` 折叠二元/一元/三元/强转（含浮点；`-3.5` 取反按 `-a.f` 折叠）
- **常量传播**：已知常量经 `constVal` 标记传递
- **循环展开**：`#pragma unroll` + `--unroll-limit`；支持 `for (i = 0; i < n; i++)`
  与 `i = i + 1` 赋值步进、部分展开、变量遮蔽处理
- **DCE**：死代码消除
- **强度削减**：无符号整数的 `*`/`/` 2 的幂 → 移位

`-O2` 真实生效（已验证：t7 展开后字节码更大、t6 常量折叠后更小，输出 O0==O2）。

## 5. 代码生成（src/codegen.cpp + codegen2.inc）

- **两遍**：`measureAll()` 计数 + 记录每实例 `labelPos_`，emit 遍用 `codeOff_[idx]`
  作为分支目标基址；`newLabel` 计数器每遍重置，保证两遍标签名一致
- **寄存器**：R0–R15；`pushReg/popReg/loadSlot/storeSlot` 封装；`pushConst` 用 R0
- **作用域/调用**：`SCOPE_BASE` = 进入时的 `stackPtr`；`SCOPE_PUSH` 记录栈底并加深
  层级，`SCOPE_POP` 恢复栈指针；调用返回值先落寄存器、`SCOPE_POP` 后再压栈（机器深度净零）
- **分支**：`branchOnFlag` 计算 `flag*(t-f)+f` 绝对地址，`MOVI/MUL/ADD/JMP_IND` 发射
- **主函数序言**：`STACK_INIT` + `GET_ADDRS` + 循环清零 ECS world 堆
- **栈/作用域配置**：`--stack` 显式覆盖栈大小（递归与非递归均生效）；默认递归栈 1MB
  （约 1.5 万层深递归）；scopeSize 随栈大小放大
- **修复历史**：`UnaryOp::Neg` 曾因 `pushConst` 复用 R0 把 `-7` 算成 0，改为
  「先压 0 再压操作数再相减」；浮点取反折叠按 `-a.f` 处理；
  深递归曾因作用域栈/数据栈越界写导致堆损坏（VM 已改为动态扩容，见 02 文档）

## 6. j8run 宿主运行器（runtime/j8run.cpp）

`j8run` 不是独立 VM：它 `#define main jadeight2_vm_main` 后 `#include`
`../Jadeight2/main.cpp`，因此解释语义与 Jadeight2 VM 完全一致。用法
`./build/j8run out.bc [--externs manifest] [--lib lib.so ...]`。
它是**当前唯一可直接运行 `.bc` 的入口**（Jadeight2 独立二进制 `main()` 不带参数）。

### 外部函数（extern / EXTERN_CALL）

.j8 里用 `extern 返回类型 函数名(类型, ...);` 声明外部 C 函数，j8c 用
`-emit-externs manifest.txt` 输出签名清单（`名字:返回类型(参数类型,...)`），j8run 用
`--externs` + `--lib` 加载动态库并注册（libffi 透传，VM 的 EXTERN_CALL 零封装调用）：

```c
extern i32 mymul_int(i32, i32);   // 声明
void main() { print(mymul_int(6, 7)); }   // 42
```

```bash
gcc -shared -fPIC mylib.c -o libmylib.so
./build/j8c -O0 -emit-externs externs.txt -o out.bc prog.j8
./build/j8run out.bc --externs externs.txt --lib libmylib.so
```

（修复历史：j8run 注册外部函数曾有两个悬垂指针 bug——`&g_cifs.back()` 被 vector 扩容
失效，以及 `ffi_prep_cif` 只存指针不拷贝、局部 `atypes` 数组随函数返回销毁；已改用
`deque<ffi_cif>` + 全局保存 arg_types 数组修复。另有 `externMemcpy`/`externFree` 曾在
`SCOPE_PUSH` 之后才求值参数，导致 mode0 加载用错作用域基址、free 收到非法指针；
已改为先求值到 R4.. 再压栈。实测可通过 FFI 调用 C++ 标准库（std::string/std::map/
std::sort/std::cmath）与系统库（libm、zlib compress2/uncompress 往返 + 数据校验），
示例见 `JadeightPoject/ffi-test/`。）

## 7. 测试与已知问题

- 测试：`tests/run_tests.sh` 对 `tests/*.j8` 在 `-O0`/`-O2` 下
  编译运行并与 `.expected` 逐行比对，**当前 14/14 全绿**（7 测试 × 2 级别）
- 已知问题：
  - `-O2` 为实验性/不稳定优化级别，默认建议 `-O0`
  - 整数字面量默认无符号（`0 - 7` 按 u32 回绕）
  - `x * y;` 形式会被解析为指针变量声明（与 C 的 typedef 消歧同理）
