# Jadeight 生态总体架构

Jadeight 是一个自底向上的字节码虚拟机生态，共四个工程：

| 工程 | 角色 | 关键产物 | 文档 |
|---|---|---|---|
| `../Jadeight2` | 字节码虚拟机（解释器） | `Jadeight2` 可执行文件 | [02-Jadeight2虚拟机.md](02-Jadeight2虚拟机.md) |
| `../JadeightAbstractionCode` | 汇编层：jasm 文本 → 字节码 | `jadeight_asm.hpp`、`jasm` | [03-汇编器与字节码格式.md](03-汇编器与字节码格式.md) |
| `../JadeightCompiler` | C 风格编译器 `j8c` | `build/j8c`、`build/j8run` | [04-j8c编译器.md](04-j8c编译器.md) |
| 本目录 `JadeightPoject` | 启动器：自动找 VM、跑字节码 | `JadeightRunner`（单 exe）、`run.sh` | [05-JadeightPoject启动器.md](05-JadeightPoject启动器.md) |

## 数据流

```
.j8 源码
  │  j8c（JadeightCompiler）—— 词法/语法/语义/优化/代码生成
  ▼
.jasm 汇编文本
  │  jadeight_asm（JadeightAbstractionCode）—— 汇编器
  ▼
.bc 字节码（LE 头：argSize/retSize/entry + 指令流）
  │  Jadeight2 虚拟机（解释执行；j8run 为宿主运行器）
  ▼
程序输出
```

## 组件关系

- **j8c 编译** `.j8` 源文件，产出 `.jasm` 文本；`driver.cpp` 直接 `#include "jadeight_asm.hpp"` **复用汇编层**，一步产出 `.bc`。
- **.bc 格式** 由汇编层定义，与 Jadeight2 的 `FunctionSave::loadFromFile/saveToFile` 兼容：LE 文件头（`argSize`/`retSize`/`entry` 各 u32）+ 指令字节流。
- **Jadeight2 虚拟机** 是唯一执行者：解释 .bc，支持寄存器（R0–R15）、作用域（SCOPE_PUSH/POP）、堆分配（NEW_ARRAY）、外部调用（EXTERN_CALL/libffi）、可选 LLVM JIT。
- **j8run**（JadeightCompiler/runtime/j8run.cpp）不是独立 VM，而是宿主运行器：`#define main jadeight2_vm_main` 后 `#include` Jadeight2 的 `main.cpp`，因此解释语义与 VM 完全一致；它接受 `.bc` 路径参数，是**当前唯一可直接运行 .bc 的入口**（Jadeight2 独立二进制 `main()` 不带参数，只跑内置演示）。
- **JadeightPoject 启动器** 把这些串起来：自动寻找可运行 .bc 的 VM（本机命中 j8run），依次运行 `./byteCode/*.bc`。
